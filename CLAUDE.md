## Navigation & Context
- When user says 'look at this' or 'yes look at it', immediately read the referenced file content — do not summarize or guess
- Always verify which git branch you're on before assessing work status
- When working in multi-folder projects, confirm the correct directory before making changes

## Data & Geospatial Pipelines
- When working with coordinate data, always verify lat/lon ordering and CRS alignment before processing
- When merging datasets with dates, check timezone alignment to avoid zero-overlap merges
- Validate visualization parameters (e.g., min/max ranges) before rendering satellite imagery
